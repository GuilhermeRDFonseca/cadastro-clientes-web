# Cadastro de Clientes Web

Aplicação web simples para cadastro de clientes, permitindo criar, listar, editar e excluir registros.
O projeto foi desenvolvido utilizando HTML, CSS, JavaScript e JSON-Server.

## Funcionalidades
- Cadastro de clientes
- Listagem em tabela
- Edição de dados
- Exclusão de registros

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript
- JSON-Server

## Como executar o projeto localmente

### Pré-requisitos
- Node.js instalado
- JSON-Server instalado

Caso não tenha o JSON-Server:
```bash
npm install -g json-server
